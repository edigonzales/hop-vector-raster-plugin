[[installation]]
== Installation

=== Voraussetzungen

* Java 21; zusätzlich wird Java 25 geprüft. Diese Plugin-Version wird gegen Apache Hop 2.19.0 gebaut.
* Das separate https://github.com/edigonzales/hop-geometry-type-plugin[Geometry-Type-Plugin],
  mindestens `0.2.0-SNAPSHOT` mit Z/M-Serialisierungsupdate oder ein kompatibler neuerer Build.
* Das separate https://github.com/edigonzales/hop-raster-type-plugin[Raster-Type-Plugin]
  passend zur Vector/Raster-Version; der aktuelle Build verwendet `0.1.0-SNAPSHOT`.
* Schreibrechte im Zielverzeichnis; Ausgabeverzeichnisse müssen bereits existieren.

Das Plugin-ZIP enthält seine Rasterbibliotheken sowie SQLite JDBC.
Das Geometry-Type-Plugin stellt den Geometry-Datentyp und die gemeinsame GeoTools-/Imagen-Runtime direkt für den gemeinsamen Classloader `sogeo-geometry` bereit. Vector/Raster wiederholt dessen Ordner nicht in `dependencies.xml`, damit dieselben Imagen-Ressourcen nicht über relative Pfad-Aliase doppelt geladen werden; dort stehen nur die Raster-Type-Ordner. Das Vector/Raster-ZIP enthält keine eigenen Geometry-/JTS-Kopien. Bei Updates den gesamten Vector/Raster-Ordner ersetzen.
Es werden weder GDAL noch eine Hadoop-Installation benötigt.

=== Release installieren

. Beenden Sie Hop vollständig.
. Installieren beziehungsweise aktualisieren Sie das Geometry-Type-Plugin gemäss dessen Anleitung.
. Installieren Sie zusätzlich das passende https://github.com/edigonzales/hop-raster-type-plugin[Raster-Type-Plugin] (`plugins/misc/hop-raster-type`).
. Laden Sie die Datei `hop-vector-raster-plugin-<version>.zip` aus dem
  https://jars.interlis.guru/releases/ch/so/agi/hop-vector-raster-plugin/[Maven-Repository]
  herunter.
. Stellen Sie sicher, dass genau eine Installation des Vector-Raster-Plugins vorhanden ist.
  Verwenden Sie für einen Versionswechsel ein vollständig ersetztes Verzeichnis `plugins/transforms/vector-raster`.
. Entpacken Sie das ZIP direkt im Hop-Hauptverzeichnis. Danach muss `plugins/transforms/vector-raster/` vorhanden sein.
. Starten Sie Hop neu und suchen Sie unter *Geospatial* nach den Vector- und Raster-Transforms.

[source,text]
----
HOP_HOME/
└── plugins/
    ├── misc/
    │   ├── hop-geometry-type/
    │   └── hop-raster-type/
    └── transforms/
        └── vector-raster/
----

Kopieren Sie keine zusätzlichen JTS- oder Geometry-JARs manuell in andere Plugin-Verzeichnisse; verwenden Sie die mitgelieferten ZIPs.
Fehlende Transforms oder Fehler beim Laden von Geometry beziehungsweise Raster deuten oft auf eine unvollständige oder doppelte Installation hin.

=== Plugin-Kontrolle

Unter *Geospatial* stehen diese Transforms zur Verfügung:

[cols="2,2",options="header"]
|===
|Transform |Plugin-ID
|<<vector-reader,Vector Reader>> |`SOGIS_VECTOR_READER`
|<<vector-writer,Vector Writer>> |`SOGIS_VECTOR_WRITER`
|<<filegdb-catalog-reader,FileGDB Catalog Reader>> |`SOGIS_FILEGDB_CATALOG_READER`
|<<filegdb-writer,FileGDB Writer>> |`SOGIS_FILEGDB_WRITER`
|<<raster-reader,Raster Reader (GeoTools)>> |`SOGIS_RASTER_READER`
|<<raster-clip-dialog,Raster Clip (GeoTools)>> |`SOGIS_RASTER_VALUE_CLIP`
|<<raster-reproject,Raster Reproject (GeoTools)>> |`SOGIS_RASTER_VALUE_REPROJECT`
|<<raster-statistik,Raster ZonalStats (GeoTools)>> |`SOGIS_RASTER_VALUE_ZONAL_STATS`
|<<raster-info,Raster Info (GeoTools)>> |`SOGIS_RASTER_INFO`
|<<raster-writer,Raster Writer (GeoTools)>> |`SOGIS_RASTER_WRITER`
|===

Die Pipeline speichert die Plugin-ID im `type`-Element des Transforms.
Bei einem unbekannten Transform prüfen Sie diese ID und die Installation.

Die alten IDs `SOGIS_RASTER_CLIP`, `SOGIS_RASTER_REPROJECT` und `SOGIS_RASTER_ZONAL_STATS`
bezeichnen nur Legacy-Transforms. Sie melden einen Migrationsfehler; die neue Verarbeitung verwendet
Rasterwerte. Die <<raster-migration,Migrationsanleitung>> beschreibt den Umstieg.

=== Für Entwickler

Build und lokale Installation sind in der {repo}/blob/main/docs/dev-setup.md[Entwickleranleitung] beschrieben.
Bauen und installieren Sie zuerst die Maven-Artefakte des Raster-Type-Repositories und entpacken Sie
dessen passendes ZIP in Hop. Das Skript `scripts/dev-sync-hop-plugin.sh` baut und installiert danach
Geometry Type und Vector/Raster und startet Hop GUI neu; Raster Type bereitet es nicht selbst vor.
Für die normale Benutzung genügt die Installation der Release-ZIPs.

Raster Type stellt den gemeinsamen Raster-Datentyp bereit. Seine Klassen werden nur einmal installiert;
Vector/Raster bringt den GeoTools-Adapter und die Raster-Transforms mit. Für bisherige Dateikonfigurationen
ist die Migration auf Reader → Operation → Writer erforderlich.
