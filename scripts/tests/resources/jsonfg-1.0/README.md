# OGC JSON-FG 1.0.0 schema snapshot

Unmodified schema documents retrieved on 2026-10-23 from
<https://schemas.opengis.net/json-fg/> for the OGC JSON-FG 1.0.0 standard,
<https://docs.ogc.org/is/21-045r1/21-045r1.html>.

`manifest.json` records each original URI, local filename and SHA-256. Tests resolve
all references from this manifest; they cannot fetch additional schemas online.
